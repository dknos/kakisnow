These GLBs are deterministic Blender outputs from
`tools/snow-burgers/generate-original-assets.py`. The generator imports no
source GLB, copies no texture, and uses only Blender primitives and mesh
construction in that source file. The generator and this candidate set were
created in an owner-directed AI-assisted Codex session; that process statement
does not by itself make a commercial-rights or ownership determination. They
are candidate replacements for the
locally supplied, provenance-unresolved models under
`art/source-assets/snow-burgers/`; the source files remain preserved and are
never overwritten.

The candidate set is kept separate from `public/assets/models/snow-burgers/`
until the runtime WebGPU capture and a fresh critic approve the visual and
vehicle-contract checks.  If approved, copy the exact files into the runtime
directory and regenerate the hash/validation reports. The generator defaults
to this candidate directory and refuses runtime paths unless
`--allow-runtime-output` is supplied.
